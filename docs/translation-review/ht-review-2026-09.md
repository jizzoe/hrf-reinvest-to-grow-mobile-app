## How to use this document

Every Haitian Creole value below was produced by machine translation and has **not** been reviewed by a Haitian Creole speaker. The application currently ships these words.

For each row, either confirm the Haitian Creole wording or write a correction in the last column. English and French are shown as the source meaning. You do not need to edit any code: corrections from this document are applied to the resource file by a separate approved change.

Two things to watch for in particular:

- **Money and bookkeeping words** — `Depans` (expense), `Vant` (sale), `Konfime` (confirm), `Benefis` (profit), `Montan` (amount). If an entrepreneur in Haiti would use a different everyday word, that word is better than the formally correct one.
- **Anything that states what the app did** — for example `Anrejistre sou telefòn sa a` (saved on this phone). These must not imply the record was sent anywhere.
